# Web Technologies

This repository is for my student course Web Technologies.

## About the Course

In this course, I study the basics of web development.  
The main topics are HTML, CSS, responsive design, forms, Git, hosting, and basic SEO.

## Course Topics

| Lesson | Lecture Topic | Practice Topic |
|---|---|---|
| 1 | WWW architecture and data transfer protocols | Environment setup, terminal, Git |
| 2 | HTML5 semantics and document structure | Creating a semantic web page |
| 3 | CSS box model and element positioning | Selectors, colors, and typography |
| 4 | Flexbox layout | Navigation and product cards |
| 5 | CSS Grid and responsive design | Responsive multi-column layout |
| 6 | HTML5 forms, validation, and data collection | Creating forms with different input types |
| 7 | Graphics optimization and layout performance | SVG, icons, and media queries |
| 8 | Hosting, deployment, and SEO basics | Publishing a project on GitHub Pages or Vercel |

## Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Git
- GitHub
- GitHub Pages or Vercel

After completing this course, I will have a basic website created with HTML and CSS.
